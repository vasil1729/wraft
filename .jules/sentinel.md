## 2024-11-20 - Gnuplot Command Injection and Insecure Temporary Files
**Vulnerability:** The `generate_gnu_gantt_chart/2` function was vulnerable to OS command injection via unescaped string interpolation in Gnuplot `.plt` files. It also created predictable temporary files (`temp/gantt_chart_input/`) leading to race conditions or unauthorized access, and failed to properly sanitize uploaded file names (path traversal risk).
**Learning:** String interpolation into interpreted script files like `.plt` behaves like OS command injection if variables are not properly escaped. Temporary files for processing should use UUID-based sandboxed directories with a `try/after` cleanup.
**Prevention:** Always escape inputs placed inside script templates using strict replacement (e.g., escaping slashes, quotes, backticks, and newlines). Always use UUIDs in `System.tmp_dir!()` for temporary processing and `Path.basename/1` combined with regex sanitization (`~r/[^a-zA-Z0-9_\-\.\ ]/`) for user-supplied filenames.
