## 2024-05-25 - Prevent Command Injection and Path Traversal in Gnuplot Gantt Chart Generation
**Vulnerability:** Gnuplot template scripts used for generating Gantt charts allowed path traversal and unescaped command injection through filenames and titles injected directly into string contexts without escaping. Gnuplot shell calls were missing proper file cleanup.
**Learning:** Using template strings and `String.replace` to fill dynamic values (like input or output paths) in command scripts directly leads to severe command injection if user inputs (such as paths or names) aren't strictly sanitized/escaped. Temporary files directly under `temp/` without namespacing also led to race conditions.
**Prevention:** Always escape backslashes, quotes, backticks, and newlines before inserting values into execution templates (like `.plt` scripts). Use sanitization for dynamically generated paths (e.g., `Path.basename()` and restrict character sets) and generate UUIDs for temporary directories to avoid collisions. Use `try/after` to ensure filesystem cleanup.
