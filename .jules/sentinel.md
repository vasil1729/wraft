## 2024-07-20 - [Command Injection & Path Traversal in Gnuplot Gantt Chart]
**Vulnerability:** OS command injection and path traversal were present in `generate_gnu_gantt_chart/2`. Input `filename` and `title` from CSV uploads were concatenated directly into a Gnuplot `.plt` template, enabling injection of arbitrary Gnuplot/shell commands via variables and filesystem access escapes. Additionally, a static `cp` command via `System.cmd` and global temp directories could cause collisions and command execution.
**Learning:** String interpolation without escaping in templated executable files (like `.plt` shell/Gnuplot scripts) is identical to OS command injection. Elixir's `System.cmd` is safe from typical shell injection due to taking a list of arguments, but if the script being executed itself contains injected commands from user data, the vulnerability remains.
**Prevention:** Strictly enforce a whitelist for filenames, properly escape backslashes, quotes, backticks, and newlines for variables interpolated into `.plt` files. Use explicit UUID-based temporary directories, utilize standard library file copying (`File.cp!`) over shell commands, and properly remove directories with `File.rm_rf!` in temporary scopes.
